# Bake Groups Tool for Blender

Bake Groups Tool prepares HP/LP bake groups, matching, subgroups, smoothing,
cages and FBX exports in Blender while preserving the workflow and compact UI
of the original Maya edition.

## Requirements

- Windows x64
- Blender 4.2 or newer

PySide6 and the native Blender acceleration module are included. No separate
Python packages or native executables need to be installed.

## Installation

Install the downloaded ZIP through **Edit → Preferences → Add-ons → Install
from Disk**, enable **Bake Groups Tool**, then open **N → Bake Tools → Open Bake
Group Manager** in a 3D View.

The visual PureRef manual is included at `Bake_Tools_Blender/assets/Manual.pur`
and can be opened using **About → Show manual**.
