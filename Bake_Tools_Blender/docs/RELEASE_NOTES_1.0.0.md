# Bake Groups Tool for Blender 1.0.0

First public Windows x64 release of the Blender port.

- Maya-style two-column PySide6 manager hosted by Blender's Bake Tools Sidebar.
- HP/LP membership, material-aware chapters, Analyze HP and Assign LP.
- HP-LP Matcher, subgroup isolation/colors, ZBrush classification and mesh checks.
- Cage generation/editing, Smooth preview, Find Sim/Find All and FBX export.
- English, Russian, Japanese and Simplified Chinese localization.
- Debug Log and privacy-safe Support Package.
- Explicit SHA-256 verified GitHub updater with restart-safe rollback.
- Optional, consent-based installation statistics shared with the Maya edition.
- Immediate native recovery after Blender popups close, including during MMB orbit.
- Artist-authored PureRef manual available from About -> Show manual.
- Separate marketplace archive with bilingual root installation instructions.

Target: Blender 4.2+ on Windows x64. The bundled native cp313 accelerator is
used by Blender 5.1; other supported Python ABIs use the Python fallback.
